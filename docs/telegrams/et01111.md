## 概要

影響をもたらす津波が到達すると予測された地域、または影響がなくなった地域に対して、津波警報・注意報・予報の発表・切替及び解除について、
予報区（対応する市町村名等や、対応する地域や予報区境界等の補足説明を含む）ごとの予想の高さや津波到達時間、震源要素等を発表

**2027年03月頃から配信開始**

**資料名** <br/>
津波警報・注意報・予報

**配信形式** <br/>
気象庁防災情報XMLフォーマット

**データ種類コード** <br/>
VTSE42

**/Report/Control/Title** <br/>
津波警報・注意報・予報b

**WebSocket圧縮形式** <br/>
gzip
