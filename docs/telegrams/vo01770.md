## 概要

火山噴火発生時の火山灰による重大な災害が起こるおそれが高まったことを伝える火山灰警報等を提供する

**2027年度中に気象庁の新システムへの火山灰警報等の提供機能の整備を完了予定。整備完了後早期に警報等の提供開始を予定**

**資料名** <br/>
火山灰警報・注意報

**配信形式** <br/>
気象庁防災情報XMLフォーマット

**データ種類コード** <br/>
VFVO70

**/Report/Control/Title** <br/>
火山灰警報・注意報

**WebSocket圧縮形式** <br/>
gzip
